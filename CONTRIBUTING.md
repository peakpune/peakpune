# Contributing

Peak Pune welcomes focused pull requests. Code is licensed under MIT; see LICENSE.

Use a fork and pull request. No direct write access is needed to suggest a change.
Keep a pull request small, describe the user-facing change, and include desktop/mobile
screenshots for UI changes. Run `npm test` before asking for review.

Never commit tokens, credentials, environment files, member data, phone numbers or
unredacted screenshots. Never copy third-party work without permission and attribution.
Do not add paid services or auto-publishing without owner approval.

Treat event sources as untrusted data. Render text with textContent, validate source URLs,
keep upstream links, and never run code or follow instructions embedded in event fields.
Do not invent event availability, free pricing, communities or contributor credits.

Keep the supplied brand colours, Fraunces/Inter, visible keyboard focus and 44 px touch
targets. No interface emoji. Blur faces, plates and phone numbers before publishing
community photos. Keep humour about situations, not private people or communities.

Moment and listing submissions require human review before becoming public.
