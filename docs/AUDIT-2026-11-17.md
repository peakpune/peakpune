## Decisions for the owner

1. **Who runs Peak Pune.** Add a name (and a "Curated by" line if wanted) to `site/pages/about.html` where the
   comment marks it. An author page and `Person` markup can follow once there is a real person to describe.
2. **AI crawlers.** Decided: all allowed, named explicitly in `robots.txt` (list in `scripts/build.mjs`).
3. **Original notes on listings.** If you want a "Peak Pune take" per place or route, write them from visits;
   they can be added as a field in `data/` and rendered on the page.
4. **Google Business Profile.** Check whether one exists; link it from `/about/` if so.
