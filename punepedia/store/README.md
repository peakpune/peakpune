# Store assets

| File | Play Console field |
|---|---|
| `play_store_icon_512.png` | App icon (512 × 512, no transparency) |
| `feature_graphic_1024x500.png` | Feature graphic |
| `screenshots/*.png` | Phone screenshots (1030 × 2060, 2:1) |

The launcher icon in `android/app/src/main/res/mipmap-*` uses the same artwork.

Screenshots were captured from the web build of this code at phone size. Retake them when content changes. Before using them in the listing, note:

- They show the app as a reader sees it before buying the unlock, except `05-unlocked-story.png`, which shows a full story after unlocking.
- The price shown on the unlock button comes from Google Play; the screenshots use ₹199.00.
