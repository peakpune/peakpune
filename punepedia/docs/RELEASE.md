# Release notes (not yet released)

Nothing in this repository publishes, deploys or buys anything. These are the steps to take **with approval**, when the time comes.

## 1. Pass the gates
```bash
python3 tools/content.py build
python3 tools/content.py release-check   # must pass
flutter analyze && flutter test
```
Then the manual checklist in `docs/TEST_CHECKLIST.md`.

## 2. Map (removed)
The in-app map was removed on 2026-10-31. OpenFreeMap (https://openfreemap.org) is free with commercial use allowed and no API key, and was the intended provider, but its vector tiles could not be verified rendering with `vector_map_tiles` 8.0.0 in this build (the package does not support web, and it never loaded tiles in a Flutter test probe). Places with verified coordinates instead link to Google Maps (free URLs, no key). To bring a map back, restore `lib/ui/map/map_screen.dart` from git history (commit before the removal) and test it on a real Android phone first.

## 2b. In-app product
Create the one-time product `punepedia_full_unlock` at ₹199 — steps in `docs/PURCHASE_MODEL.md`.

## 3. Signing (keys never enter the repo)
```bash
keytool -genkey -v -keystore ~/keys/punepedia-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```
Create `android/key.properties` (git-ignored):
```
storePassword=…
keyPassword=…
keyAlias=upload
storeFile=/home/you/keys/punepedia-upload.jks
```
Then in `android/app/build.gradle.kts` (generated by `flutter create`), load `key.properties` and add a `release` signing config, following Flutter's “Build and release an Android app” guide. Use Play App Signing so Google holds the app signing key. Back up the upload key separately.
